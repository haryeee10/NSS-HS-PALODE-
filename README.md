# NSS-HS-PALODE-
NSS HS Palode is a private aided, co-educational Malayalam-medium school in Thiruvananthapuram, Kerala, established in 1957. Serving grades 5–10, it features 5 classrooms, a library with 5,000 books, a 12-computer lab, a playground, functional tap water and toilets, an all-weather access road, and on-site mid-day meal preparation.
